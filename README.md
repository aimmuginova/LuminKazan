# LuminKazan

LuminKazan - веб-приложение на ASP.NET Core MVC для профессионального фотографа.

## Описание проекта

Проект разработан в рамках курсовой работы по теме:  
"Создание интерактивного веб-портфолио для профессионального фотографа".

Веб-приложение объединяет публичную часть сайта и административную панель для управления заявками, расписанием, услугами, студиями, портфолио и отзывами.

## Основные возможности

- публичная часть сайта фотографа;
- просмотр услуг, студий, портфолио и отзывов;
- форма записи на фотосъемку;
- проверка доступности времени записи;
- административная панель;
- управление заявками и расписанием;
- управление услугами и студиями;
- управление портфолио;
- модерация отзывов;
- защита административной панели через авторизацию.

## Технологии

- ASP.NET Core MVC
- C#
- Entity Framework Core
- SQL Server
- ASP.NET Core Identity
- HTML, CSS, JavaScript
